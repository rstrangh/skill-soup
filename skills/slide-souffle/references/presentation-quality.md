# Presentation quality rubric

Score five dimensions 1–5 each. Normalize the average to 0–100.

1. **Narrative clarity** — clear thesis, understandable progression, necessary and ordered
   sections, an ending that resolves the central idea.
2. **Information design** — each slide's main point obvious, complexity reduced without
   misleading, efficient diagrams, visible hierarchy.
3. **Visual communication** — visuals explain, typography readable and hierarchical, layout
   consistent without monotony, contrast, spacing and density fit.
4. **Audience fit** — assumed knowledge matches the audience, jargon explained, examples
   meaningful, detail fits setting and purpose.
5. **Speaker support** — slides leave room for the speaker, transitions and reveals
   supported, notes and appendix used, the story works without reading the screen.

| Score | Meaning |
|---|---|
| 90–100 | exceptional and deliberate |
| 75–89 | strong, with clear improvements |
| 60–74 | competent, inconsistent |
| 40–59 | substantial communication problems |
| 0–39 | the deck obstructs the talk |

The evidence and recommendations carry more weight than the number.
