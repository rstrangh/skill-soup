# Glossary

Canonical spellings for names and project terms that speech recognition gets wrong. If a word
in the monologue sounds like a term in this table, write the term as listed. Project terms are
never semantic anchors.

| Term | What it is |
|---|---|
| Claude | Anthropic's model family |
| Claude Code | Anthropic's coding agent CLI |
| Skill | A directory with a `SKILL.md` that an agent loads on demand |
| Matt Pocock | TypeScript educator and author of agent skills |

On a conflict, the user's `~/.config/brain-salad/glossary.md` wins.
