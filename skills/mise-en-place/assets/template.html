The blindspots

Landmine

Evidence

Why it bites this task
If you copy Google, Okta logins never set the CSRF cookie and every form post after login fails.
Prompt fix
Base the Okta provider on the GitHub provider, not on Google. Google bypasses the session middleware on purpose.
